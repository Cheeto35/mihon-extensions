# mihon-extensions

Personal self-hosted extension repo for [Mihon](https://mihon.app/).

## Adding this repo to Mihon

1. In Mihon, go to **More → Settings → Browse → Extension repos**.
2. Add the full path to `index.min.json` (not just the folder):
   `https://raw.githubusercontent.com/Cheeto35/mihon-extensions/main/index.min.json`
